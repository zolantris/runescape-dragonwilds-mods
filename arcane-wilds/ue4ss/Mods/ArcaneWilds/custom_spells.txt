# Arcane Wilds Custom Spell Scaffolding (Hot-Reloaded Automatically on Save!)
# Define custom spells that wrap an existing DominionSpellData base spell and attach
# custom VFX (Niagara / SpawnActor / GameplayEffect), SFX (SoundWave / SoundCue),
# AnimMontage, and Speed/Clamp settings at runtime—without .pak asset overrides.
#
# Block Format:
#   [CustomSpellName]
#   BaseSpell = <DA_Spell_*, HAM_*, or DA_AncientStaff_* asset name>
#   Category  = <Category tag for chaining & movement unlock, e.g. Fire, Air, Water, Earth, AncientMagicks>
#   VFX       = <Optional NiagaraSystem / Actor / GameplayEffect object name>
#   SFX       = <Optional SoundWave / SoundCue object name>
#   Montage   = <Optional AnimMontage object name>
#   Speed     = <Optional speed multiplier >= 1.0, e.g. 2.0>
#   Clamp     = <Optional true/false; true caps high speeds at MaxFinisherSpeedClamp (default 5.0x) so AnimNotifies aren't skipped>
#   RuneCost  = <Optional rune alias or item name, e.g. fire, air, blood, ice>
#   RuneCount = <Optional integer quantity >= 1, default 1>
#
# Once defined here, you can reference [CustomSpellName] directly in combo_rules.txt!
# Example: Fire@bolt_1,bolt_2:2.0 -> FlamesOfZamorak@FlamesOfZamorak:1.8 :5;
